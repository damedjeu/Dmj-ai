# Architecture de DMJ AI

## Vision

DMJ AI est une plateforme SaaS alimentée par l'intelligence artificielle destinée aux entrepreneurs, créateurs de contenu et étudiants en Afrique.

## Architecture générale

```
Application Flutter
        │
        ▼
    API Backend
        │
        ▼
    Base de données (Supabase)
        │
        ▼
Services d'IA (OpenAI et autres)
```

## Modules

- Splash Screen
- Authentification
- Tableau de bord
- DMJ One Click
- Génération de contenu IA
- Génération d'images IA
- Paiements (Orange Money, MTN MoMo, Stripe)
- Profil utilisateur
- Paramètres
